# knowledgebase-raw-scraping-youtube — 유튜브 스크립트 적재

채널의 말(speech)을 지식 베이스의 바닥(`raw/`)으로 옮기는 **원자 스킬**. 판단하지 않고 옮기기만 한다.

> 영상은 **다시 볼 수 있지만 검색할 수 없다.** 그래서 스크립트를 `raw/`에 넣는다 — 단, 기계가 들은 것과 사람이 말한 것을 구별해서.

## 이 스킬의 자리

```
[나중에] /자료수집  (상위 오케스트레이터 — 아직 없음)
   ├─ Skill▶ knowledgebase-raw-scraping-github
   ├─ Skill▶ knowledgebase-raw-scraping-youtube   ← 이 스킬
   └─ Skill▶ (예정) slack · figma · db · paste
```

`.meta.json` 공통 칸과 워터마크 형식은 `knowledgebase-raw-scraping-github` 와 **같다**(`source` 값만 `youtube`). 상위 스킬이 생겨도 형식 통일 작업이 없게 맞춰 둔 것.

## 선행: yt-dlp

```bash
command -v yt-dlp || python3 -m venv ~/.local/venv/ytdlp && ~/.local/venv/ytdlp/bin/pip install -U yt-dlp
# 또는: pipx install yt-dlp
```

- **전역 `pip install` 은 최근 배포판에서 막혀 있다**(PEP 668 externally-managed). venv 나 pipx 를 쓴다.
- 스크립트는 `--ytdlp <경로>` 로 받거나 PATH 에서 찾는다. **없으면 설치 안내만 하고 종료한다** — 자동으로 시스템에 설치하지 않는다.
- `ffmpeg`·whisper 는 **필요 없다.** 자막만 받고 음성은 건드리지 않는다.
- yt-dlp 가 *"No supported JavaScript runtime"* 경고를 낼 수 있다. 자막 추출에는 영향이 없다(실측 확인). 경고가 거슬리면 `deno` 를 깔면 사라진다.

## 긁는 것 / 안 긁는 것

| | 긁나 | 왜 |
|---|---|---|
| 자막 (수동) | ✅ | uploader 가 쓴 글 |
| 자막 (자동·ASR) | ✅ **단 등급 상한 있음** | 기계가 사람 말을 추측한 것 (§등급) |
| 영상 설명란 | ✅ | uploader 가 쓴 글. 자막보다 신뢰도 높다 |
| 제목·업로드일·길이 | ✅ | 메타 |
| 댓글 | ❌ 기본, `--comments` 로 opt-in | 수백~수천 건이 들어와 노이즈가 지식을 묶는다 |
| 조회수·좋아요 | ❌ | 매일 바뀌는 값은 `raw/`(그 시점의 사진)에 맞지 않는다. 지표는 `event`/`spec` 페이지에서 조회 시점과 함께 적는다 |
| 영상·음성 파일 | ❌ | 저장소에 바이너리를 넣지 않는다 |

## 등급 — 이 스킬이 추가하는 단 하나의 규칙

`schema/rules.md` 에 **원천 신뢰도 상한** 한 줄을 넣는다(없으면 이 스킬이 제안한다):

> 자동 자막(ASR)에서 온 내용은 **최고 문서상**이고, 그중 **숫자·고유명사·인용은 `[추론]`** 이다.
> 사람이 해당 타임스탬프를 확인하면 문서상으로 올린다. 수동 자막은 그냥 문서상이다.

왜 필요한가 — 자동 자막은 조용히 틀린다. 실제로 자주 깨지는 것:

```
사람이 말한 것          ASR 이 들은 것
3할 2푼 7리        →   32푼 7리 / 3할 이분 칠리
오타니              →   오타 니 / 오 타니
OPS 0.950          →   OPS 영점 구오공 / OPS 0.95
작년 포스트시즌      →   작년 포스트 시즌
```

숫자가 틀린 채 `spec`·`concept` 페이지로 들어가면, 그 뒤 모든 계산이 조용히 틀린다. 그래서 **ASR 숫자는 사람이 영상을 보고 확인해야만** 올라간다. 파일 머리와 `.meta.json` 의 `caption_kind` 가 그 판정 근거다.

## 단계

### 0. 선행 확인

```bash
ls <KB_ROOT>/schema/rules.md                 # 없으면 knowledgebase-setup 먼저
cat <KB_ROOT>/state/youtube-watermark.json 2>/dev/null
```

채널 링크를 사용자에게 받는다(`@handle` · `/channel/UC…` · `/c/…` · 재생목록 전부 가능).

### 1. 먼저 `--dry-run` — 자막이 있는지부터 본다

`info.json` 에 `subtitles`(수동)·`automatic_captions`(자동) 목록이 들어오므로 **자막을 받지 않고도 유무를 안다.** dry-run 은 영상당 정보 추출 1회뿐이다.

```bash
python3 scripts/scrape_youtube.py --kb <KB_ROOT> --channel <URL> --lang ko,en --dry-run
```

출력 예:

```
채널: @bluefield_mlb   영상 127개 (업로드일 역순, limit=50 적용)
  자막 있음(수동)  3개
  자막 있음(자동)  41개
  자막 없음        6개     ← 적재 불가. ASR을 직접 돌려야 하고 이 스킬은 안 한다
```

**자막이 아예 없는 채널이면 여기서 멈춘다.** 음성 인식은 이 스킬의 범위가 아니다(ffmpeg + whisper 가 필요하고, 품질·비용·시간이 전혀 다른 작업이다). 사용자에게 알리고, 필요하면 별도 작업으로 뺀다.

### 2. 적재

```bash
python3 scripts/scrape_youtube.py --kb <KB_ROOT> --channel <URL> \
  --lang ko,en [--limit 50] [--since 20260101] [--comments]
```

- **파일은 불변**: 영상 스크립트는 나중에 바뀌지 않으므로 이미 있는 파일은 **건너뛴다**(덧붙이지도 않는다). 수동 자막이 나중에 추가된 경우만 `-manual` 파일을 **따로** 만들고, 기존 자동 자막 파일은 **지우지 않는다**(그걸 가리키는 인용이 거짓이 되므로).
- **증분**: `state/youtube-watermark.json` 의 채널별 마지막 업로드일 이후만.
- **타임스탬프 유지**: 모든 줄에 `[MM:SS]`. 이게 사람이 원본으로 돌아가는 유일한 길이고, `[src:n]` 과 함께 "영상 12분 34초"를 가리키는 좌표가 된다.
- 롤링 중복 줄·타이밍 태그는 파싱에서 제거한다(자동 자막은 같은 줄을 2~3번 반복해 내려준다).
- **자동 '번역' 트랙은 받지 않는다.** 유튜브는 `ko-en`(영어에서 번역한 한국어)처럼 `<목표>-<원본>` 으로 주는데, 번역은 ASR 위에 기계 번역을 한 겹 더 얹은 것이라 숫자·고유명사가 **두 번** 깨진다. `ko-orig`·`ko-KR` 같은 원본 변종은 받는다.

### 3. 보고 — 후보만, 페이지는 안 만든다

```
적재: 영상 41개 (수동 3 · 자동 38)   건너뜀 12(이미 있음) · 자막 없음 6

지식 베이스 후보
  [새로] concept  "달러게임 점수 배분 설명"   ← 2026-09-14 영상 [08:12] (자동 자막 — 숫자 확인 필요)
  [갱신] spec     product/s-0002-랭킹기준     ← 2026-10-02 영상 [03:40] 에서 기준을 다르게 말함 (충돌)
  [새로] question "포스트시즌 포함 여부"       ← 영상과 이슈 #131 이 다름
```

ASR 출처 후보는 **반드시 "숫자 확인 필요" 를 붙인다.** 그게 없으면 사람이 그냥 넘긴다.

## 주의점

- **본인 채널·공개 자막 범위에서 쓴다.** 남의 채널을 대량으로 긁는 건 플랫폼 약관·저작권 문제가 되고, 이 스킬의 용도가 아니다(지식 베이스는 *우리* 기억이다).
- **업로드일의 정본은 `info.json` 이다.** `--flat-playlist` 는 채널 페이지에서 `upload_date` 를 `NA` 로 주기 때문에, 그 값을 믿으면 파일명이 `00000000` 이 되고 **워터마크가 전진하지 않아 증분 수집이 조용히 죽는다**(실측으로 잡은 버그). `upload_date` 는 UTC 기준이라 현지와 하루 차이가 날 수 있음을 메타에 남긴다.
- **라이브 스트림·쇼츠**가 섞여 들어온다. 쇼츠는 스크립트가 거의 없고 라이브는 자막이 늦게 붙으니, `--min-duration` 으로 걸러낸다(기본 60초).
- **yt-dlp 는 자주 깨진다.** 유튜브가 바뀌면 추출이 실패한다 — 실패를 조용히 넘기지 않고 보고하며, 먼저 `yt-dlp -U` 를 시도한다.
- `raw/`는 수정·삭제하지 않는다. 잘못 적재했으면 파일 안에 `> [적재 오류] …` 주석을 달고, 그걸 가리키는 페이지의 등급을 낮춘다.
- 이 스킬은 **읽기 전용**이다. 채널에 아무것도 올리지 않는다.
