# {{회사·서비스명}} 지식 베이스

{{한 줄 소개 — 무엇을 하는 회사/서비스인지}}의 **공통기억**이다. 사람({{쓰는 사람들}})과 에이전트가 같은 지식을 보고, 근거를 확인하고, 고친다.

> **원본은 추가만 하고, 페이지는 원본을 가리키며, 확정은 {{결정권자}}만 찍고, 검사는 코드가 한다.**

규칙 정본: **[schema/rules.md](schema/rules.md)** — 작업 전에 읽는다.

## 구조

```
schema/      규칙·타입·영역      사람만 고친다
raw/         원본(텍스트)        추가만. 수정·삭제 금지
{영역}/       페이지              areas.md에 선언된 영역
index.md     목차 + 확정 대기     스크립트가 생성
```

영역: {{영역 목록}} → [schema/areas.md](schema/areas.md)
타입: `decision` `question` `concept` `spec` `event` → [schema/types.json](schema/types.json)

## 여기에 쓰는 것 / 안 쓰는 것

| | 어디로 |
|---|---|
| 코드를 다시 읽으면 확인되는 사실 | `{{코드맥락 저장소}}` |
| 재사용 가능한 일반 개발 지식 | `{{study 경로}}` |
| 코드에서 자동 생성된 코드 위키 | 각 repo의 `{{코드위키}}` |
| **사람이 정했거나 밖에서 온 사실** | **이 지식 베이스** |

## 확정은 어떻게 찍히나

1. {{결정권자}} 발화는 **원문 그대로** `raw/confirmations/`에 붙인다 (요약하지 않는다)
2. 페이지를 고치고 PR을 올린다
3. {{결정권자}}가 PR에서 검토 → 승인하거나 직접 고친다
4. 머지되면 그 사실은 **확정** — 본문에 `[확인:{{결정권자}} YYYY-MM-DD]`

확정 전 항목은 `confirm_pending: true`로 두고 `index.md`의 「확정 대기」에 모인다.
