# 영역 (area)

영역은 **라우팅용 분류**다. 칸막이가 아니다 — 한 페이지가 걸칠 때는 `areas_also`에 적는다.

영역 폴더 `wiki/<영역>/`는 **첫 페이지가 생길 때** 만든다. 선언만 되고 빈 영역은 린트가 공백으로 올리지 않는다.

| 영역 | 무엇이 들어오나 | 주 원천 |
|---|---|---|
| `{{영역1}}` | {{무엇}} | {{원천}} |
| `{{영역2}}` | {{무엇}} | {{원천}} |
| `{{영역3}}` | {{무엇}} | {{원천}} |
